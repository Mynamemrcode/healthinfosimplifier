# HealthInfo Simplifier

HealthInfo Simplifier is an educational web application designed to make general health information easier to understand while preserving important facts and maintaining strict safety boundaries.

## Project Status
Currently in Phase 1: Problem Definition and Project Foundation.

## Core Goals
- Investigate whether AI can accurately simplify health information.
- Ensure critical facts and terminology definitions are preserved.
- Maintain transparent source attribution and strict safety boundaries.

## Technology Stack (Planned)
- Frontend: React, TypeScript
- Backend: Python, FastAPI
- AI Integration: LLM API (with secure backend key management)

## Safety Disclaimer
This application is strictly for educational purposes and does not provide medical diagnoses, treatment, or professional healthcare advice. Always consult a qualified healthcare provider for medical concerns.
